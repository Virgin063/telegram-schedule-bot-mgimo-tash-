# 🎯 Обзор проекта: Бот расписания для университета

## 📋 Описание

Telegram бот для автоматического управления расписанием студентов МГИМО Ташкент с использованием AI для парсинга Excel файлов.

## ✨ Ключевые особенности

### 🤖 AI-Powered Парсинг
- Использует **GPT-4o** для интеллектуального парсинга нечетко структурированных Excel файлов
- Автоматически исправляет ошибки и опечатки
- Распознает ФИО в неправильных графах
- Стандартизирует форматы данных

### 🔔 Умные уведомления
- Утренние уведомления с расписанием на день
- Напоминания за 15 минут до пары
- Мгновенные уведомления об изменениях расписания
- Полностью настраиваемые пользователем

### ☁️ Автоматическая синхронизация
- Автоматическая проверка Google Drive каждые 15 минут
- Обнаружение изменений в файлах
- Автоматическое обновление расписания
- Резервный ручной режим через админ-бота

### 📊 Два независимых бота
1. **Студенческий бот** - для просмотра расписания
2. **Админский бот** - для управления системой

## 💻 Технологический стек

### Backend
- **Python 3.11+** - основной язык
- **python-telegram-bot** - Telegram Bot API
- **SQLAlchemy** - ORM для работы с БД
- **PostgreSQL** - основная база данных
- **Redis** - кеширование и очереди
- **OpenAI GPT-4o** - AI парсинг

### Библиотеки
- **pandas & openpyxl** - работа с Excel
- **APScheduler** - планировщик задач
- **PyDrive2** - Google Drive API
- **loguru** - продвинутое логирование
- **pydantic** - валидация данных

### DevOps
- **Docker & Docker Compose** - контейнеризация
- **Nginx** - reverse proxy (опционально)

### 2. Студенческий бот (bots/student_bot/)

**Команды:**
- `/start` - регистрация и выбор группы
- `/today` - расписание на сегодня
- `/tomorrow` - расписание на завтра
- `/week` - расписание на неделю

**Кнопки:**
- 📅 Сегодня
- ➡️ Завтра
- 📆 Неделя
- ⚙️ Настройки

**Уведомления:**
- 🌅 Утром (7:00) - расписание на день
- ⏰ За 15 мин - перед парой
- ⚠️ Изменения - при обновлении расписания

### 3. Админский бот (bots/admin_bot/)

**Функции:**
- 📤 Загрузка Excel файлов (ручная)
- 📊 Статус системы
- 🔄 Принудительная синхронизация
- 📝 Просмотр логов
- 📈 Статистика пользователей
- 📢 Рассылка сообщений

### 4. База данных

**Таблицы:**

```sql
users              -- Студенты
- id, chat_id, group_name
- notifications_* (настройки)
- created_at, last_active

schedule           -- Расписание
- group_name, week_number
- day_of_week, start_time, end_time
- subject_name, teacher_name, room
- class_type, week_type

schedule_changes   -- История изменений
- change_type, old_value, new_value
- notified, detected_at

sync_logs          -- Логи синхронизации
- sync_type, status
- changes_detected, error_message
- synced_at, duration_seconds
```

### 5. Планировщик (tasks/scheduler.py)

**Задачи:**
1. **Синхронизация с Google Drive** (каждые 15 мин)
   - Проверяет изменения файлов
   - Скачивает и парсит при необходимости
   - Обновляет расписание

2. **Утренние уведомления** (7:00)
   - Отправляет расписание на день
   - Всем, у кого включено

3. **Уведомления за 15 мин** (динамически)
   - Перед каждой парой
   - Только тем, у кого включено

## 🚀 Быстрый старт

### 1. Установка

```bash
# Клонировать репозиторий
git clone <repo-url>
cd расписание-бот

# Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt
```

### 2. Настройка

```bash
# Создать .env
cp .env.example .env

# Отредактировать .env
# - Добавить токены ботов
# - Добавить OpenAI API ключ
# - Настроить БД
```

### 3. Запуск

```bash
# Вариант 1: Docker (рекомендуется)
docker-compose up -d

# Вариант 2: Локально
./run_all.sh

# Вариант 3: Вручную
python init_db.py
python -m bots.student_bot.main  # Терминал 1
python -m bots.admin_bot.main     # Терминал 2
python tasks/scheduler.py         # Терминал 3
```
