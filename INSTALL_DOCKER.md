# 🐳 Установка Docker Desktop для Mac

## Шаг 1: Скачивание

**Ваш Mac:** Apple Silicon (M1/M2/M3)

### Скачайте Docker Desktop:

**Ссылка для скачивания:**
👉 https://desktop.docker.com/mac/main/arm64/Docker.dmg

Или перейдите на официальный сайт:
👉 https://www.docker.com/products/docker-desktop/

## Шаг 2: Установка

1. **Откройте скачанный файл** `Docker.dmg`
2. **Перетащите иконку Docker** в папку Applications
3. **Закройте окно установщика**

## Шаг 3: Первый запуск

1. **Откройте Docker** из папки Applications (или через Spotlight: `Cmd + Space`, введите "Docker")
2. **Примите условия использования**
3. **Дождитесь запуска** (появится иконка кита в строке меню сверху)
4. **Docker готов!** Когда иконка кита перестанет анимироваться

## Шаг 4: Проверка установки

Откройте терминал и выполните:

```bash
docker --version
docker-compose --version
```

Должны увидеть версии Docker!

## ⏱ Время установки: ~5 минут

## ❓ Возможные проблемы

### "Docker требует обновления macOS"
- Обновите macOS до последней версии
- Или скачайте старую версию Docker

### "Не могу найти Docker в Applications"
- Проверьте папку Downloads
- Убедитесь, что .dmg файл скачался полностью

### "Docker не запускается"
- Перезагрузите Mac
- Попробуйте запустить снова
