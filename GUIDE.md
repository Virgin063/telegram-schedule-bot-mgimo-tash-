# 📖 Руководство пользователя

## Для студентов

### Начало работы

1. **Запуск бота**
   - Найдите бота в Telegram (ссылка от администратора)
   - Нажмите "Начать" или отправьте `/start`

2. **Выбор группы**
   - При первом запуске выберите свою группу из списка
   - Группу можно изменить позже через `/start`

### Основные функции

#### 📅 Расписание на сегодня
Нажмите кнопку **"Сегодня"** или отправьте команду `/today`

Вы увидите:
- Время каждой пары
- Название предмета
- ФИО преподавателя
- Номер аудитории
- Тип занятия (лекция/практика)

#### ➡️ Расписание на завтра
Нажмите кнопку **"Завтра"** или отправьте команду `/tomorrow`

#### 📆 Расписание на неделю
Нажмите кнопку **"Неделя"** или отправьте команду `/week`

Показывает расписание с понедельника по субботу

### ⚙️ Настройки уведомлений

Нажмите кнопку **"Настройки"**

#### Доступные уведомления:

1. **🌅 Утренние уведомления (7:00)**
   - Каждое утро получайте расписание на день
   - Удобно планировать свой день заранее

2. **⏰ За 15 минут до пары**
   - Напоминание перед каждым занятием
   - Не пропустите начало пары!

3. **⚠️ Об изменениях расписания**
   - Мгновенное уведомление при любых изменениях
   - Отмена пар, смена аудитории, смена преподавателя

Включайте и выключайте любые уведомления одним нажатием!

### Команды

- `/start` - Начать работу / сменить группу
- `/help` - Справка по боту
- `/today` - Расписание на сегодня
- `/tomorrow` - Расписание на завтра
- `/week` - Расписание на неделю

## Для администраторов

### Доступ к админ-панели

1. Убедитесь, что ваш Telegram ID добавлен в список администраторов
2. Запустите админского бота
3. Отправьте `/start`

### 📊 Статус системы

Команда: `/status` или кнопка **"Статус"**

Показывает:
- Последнюю синхронизацию
- Количество пользователей
- Количество записей в расписании
- Последние ошибки (если есть)

### 📤 Загрузка файла расписания

1. Нажмите кнопку **"Загрузить файл"** или команду `/upload`
2. Отправьте Excel файл (.xlsx) с расписанием
3. Дождитесь обработки (1-2 минуты)

Бот автоматически:
- Распарсит файл с помощью AI
- Исправит ошибки и опечатки
- Сохранит в базу данных
- Покажет статистику и предупреждения

### 🔄 Синхронизация

**Автоматическая:**
- Система автоматически проверяет Google Drive каждые 15 минут
- При обнаружении изменений скачивает и парсит файлы

**Ручная:**
- Команда: `/sync` или кнопка **"Синхронизация"**
- Принудительная проверка Google Drive
- Используйте, если нужно срочно обновить расписание

### 📈 Статистика

Команда: `/stats` или кнопка **"Статистика"**

Показывает:
- Общее количество пользователей
- Распределение по группам
- Процент включенных уведомлений
- Активность пользователей

### 📝 Логи

Команда: `/logs` или кнопка **"Логи"**

Показывает последние 20 записей логов:
- ✅ Успешные операции
- ❌ Ошибки
- ⚠️ Предупреждения

### 📢 Рассылка

Команда: `/broadcast`

Отправить сообщение всем студентам или конкретной группе.

**Использование:**
```
/broadcast
Затем отправьте текст сообщения
```

### 🔧 Управление расписанием

#### Загрузка нового расписания

1. Подготовьте Excel файл
2. Убедитесь, что структура соответствует шаблону
3. Загрузите через админ-бота

#### Обновление существующего расписания

1. Измените файл на Google Drive
2. Дождитесь автоматической синхронизации (до 15 мин)
3. Или запустите `/sync` для немедленного обновления

#### Уведомление об изменениях

При обнаружении изменений:
- Система автоматически сравнивает старое и новое расписание
- Определяет, что изменилось
- Отправляет уведомления затронутым группам

### ⚠️ Устранение проблем

#### Проблема: Файл не парсится

**Возможные причины:**
- Неверный формат Excel
- Нестандартная структура таблицы
- Слишком много ошибок в данных

**Решение:**
1. Проверьте формат файла (.xlsx)
2. Убедитесь, что структура похожа на примеры
3. Посмотрите предупреждения в ответе бота
4. При необходимости исправьте файл вручную

#### Проблема: Google Drive не синхронизируется

**Решение:**
1. Проверьте `/status` - когда была последняя синхронизация
2. Проверьте `/logs` - есть ли ошибки
3. Убедитесь, что файл на Google Drive доступен
4. Попробуйте `/sync` для принудительной синхронизации

#### Проблема: Студенты не получают уведомления

**Проверьте:**
1. `/stats` - сколько студентов включили уведомления
2. Убедитесь, что планировщик запущен
3. Проверьте логи на ошибки отправки

### 📋 Лучшие практики

1. **Регулярная загрузка**
   - Обновляйте расписание сразу после изменений
   - Не ждите автосинхронизации для срочных обновлений

2. **Проверка после загрузки**
   - Всегда проверяйте предупреждения AI
   - Выборочно проверьте расписание через студенческого бота

3. **Уведомления студентов**
   - При важных изменениях используйте `/broadcast`
   - Предупреждайте о технических работах

4. **Мониторинг**
   - Регулярно проверяйте `/status`
   - Просматривайте `/logs` на наличие ошибок
   - Следите за `/stats` для понимания активности

### 🔐 Безопасность

- Не передавайте доступ к админ-боту третьим лицам
- Храните токены ботов в безопасности
- Регулярно проверяйте список администраторов
- Делайте бэкапы базы данных

### 📞 Техническая поддержка

При серьезных проблемах:
1. Сохраните логи
2. Опишите проблему детально
3. Укажите время возникновения
4. Отправьте информацию разработчику

## Часто задаваемые вопросы (FAQ)

### Для студентов

**Q: Как изменить группу?**
A: Отправьте `/start` заново и выберите новую группу.

**Q: Почему не приходят уведомления?**
A: Проверьте настройки - кнопка "⚙️ Настройки". Убедитесь, что нужные уведомления включены (✅).

**Q: Расписание не актуально**
A: Обратитесь к администратору. Возможно, файл еще не обновлен.

**Q: Бот не отвечает**
A: Проверьте интернет-соединение. Если проблема сохраняется - обратитесь к администратору.

### Для администраторов

**Q: Как часто нужно обновлять расписание?**
A: При любых изменениях. Автосинхронизация работает каждые 15 минут, но для срочных изменений используйте ручную загрузку.

**Q: Можно ли загружать несколько файлов?**
A: Да, можно загружать файлы для разных групп последовательно.

**Q: Как добавить нового администратора?**
A: Добавьте его Telegram ID в файл `.env` в параметр `ADMIN_IDS` и перезапустите бота.

**Q: Что делать при ошибке парсинга?**
A: Проверьте предупреждения бота. Возможно, нужно вручную исправить структуру Excel файла.

**Q: Можно ли отменить рассылку?**
A: Нет, после отправки `/broadcast` остановить рассылку нельзя. Будьте внимательны!
