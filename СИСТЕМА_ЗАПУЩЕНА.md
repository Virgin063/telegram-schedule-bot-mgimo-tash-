## 📱 Как протестировать:

### 1. Студенческий бот

**В Telegram:**
1. Найдите вашего бота (username из @BotFather)
2. Отправьте `/start`
3. Выберите группу "БИ(б)-23/1"
4. Попробуйте кнопки

**Пока расписания нет**, так как нужно сначала загрузить через админ-бота!

---

### 2. Админский бот

**В Telegram:**
1. Найдите админского бота
2. Отправьте `/start`
3. Нажмите "📤 Загрузить файл"
4. Отправьте файл **"БИ 3 курс.xlsx"** из папки проекта

**Бот:**
- Скачает файл
- Отправит в GPT-4o для парсинга (~1-2 минуты)
- Исправит ошибки автоматически
- Сохранит в БД
- Покажет статистику

---

### 3. Проверка расписания

После загрузки:
1. Вернитесь в студенческого бота
2. Нажмите "📅 Сегодня"
3. Должно показать расписание!

## 🔍 Проверка системы

### Проверить запущенные процессы:

```bash
# Показать запущенные боты
ps aux | grep "bots.*main" | grep -v grep

# Показать Docker контейнеры
docker-compose -p schedule-bot ps
```

### Просмотр логов:

```bash
# Логи ботов
tail -f logs/bot.log
tail -f logs/admin_bot.log

# Логи Docker
docker-compose -p schedule-bot logs postgres
docker-compose -p schedule-bot logs redis
```

### Остановить систему:

```bash
# Остановить ботов
pkill -f "bots.student_bot"
pkill -f "bots.admin_bot"

# Остановить Docker
docker-compose -p schedule-bot down
```

### Запустить снова:

```bash
# Docker
docker-compose -p schedule-bot up -d postgres redis

# Боты (в разных терминалах)
./venv/bin/python -m bots.student_bot.main
./venv/bin/python -m bots.admin_bot.main
```

## 🆘 Если что-то не работает:

### Бот не отвечает?
```bash
# Проверьте логи
tail -f logs/bot.log

# Перезапустите
pkill -f "bots.student_bot"
./venv/bin/python -m bots.student_bot.main
```

### База данных не работает?
```bash
# Проверьте статус
docker-compose -p schedule-bot ps postgres

# Перезапустите
docker-compose -p schedule-bot restart postgres
```

### Ошибка "Invalid token"?
- Проверьте токены в `.env`
- Убедитесь, что нет лишних символов
- Получите новые токены через @BotFather
