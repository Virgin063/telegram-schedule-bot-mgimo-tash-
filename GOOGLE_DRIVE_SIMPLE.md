# 🔗 Настройка Google Drive (Упрощенный способ)

## Без настройки API! Просто публичная ссылка!

Вместо сложной настройки Google Drive API, можно использовать обычную публичную ссылку.

## 📋 Шаги настройки (2 минуты!)

### Шаг 1: Поделитесь файлом

1. Откройте ваш файл с расписанием на Google Drive
2. Нажмите правой кнопкой → **"Поделиться"**
3. В разделе "Доступ" нажмите **"Изменить"**
4. Выберите: **"Все, у кого есть ссылка"**
5. Права: **"Читатель"** (достаточно)
6. Нажмите **"Копировать ссылку"**

### Шаг 2: Добавьте ссылку в .env

Откройте файл `.env` и добавьте:

```bash
# Вставьте вашу ссылку
GOOGLE_DRIVE_PUBLIC_URL=https://drive.google.com/file/d/1abc123xyz456/view?usp=sharing

# Режим работы
GOOGLE_DRIVE_MODE=simple
```

### Шаг 3: Перезапустите систему

```bash
docker-compose restart
# или
./stop_all.sh && ./run_all.sh
```

**Готово!** Теперь система будет автоматически проверять файл каждые 15 минут.

---

## 🎯 Как это работает

1. **Каждые 15 минут** планировщик проверяет файл
2. **Скачивает** если обнаружены изменения
3. **Парсит** с помощью GPT-4o
4. **Обновляет** расписание в БД
5. **Уведомляет** студентов об изменениях

## 🔧 Форматы ссылок

Работают все эти форматы:

```
https://drive.google.com/file/d/FILE_ID/view?usp=sharing
https://drive.google.com/open?id=FILE_ID
https://drive.google.com/uc?id=FILE_ID
FILE_ID
```

## 🔄 Переключение между режимами

### Из простого режима в API:

1. Настройте Google Drive API (см. SETUP.md)
2. Измените в `.env`:
   ```bash
   GOOGLE_DRIVE_MODE=api
   GOOGLE_DRIVE_FOLDER_ID=your_folder_id
   ```
3. Перезапустите систему

### Из API в простой режим:

1. Получите публичную ссылку
2. Измените в `.env`:
   ```bash
   GOOGLE_DRIVE_MODE=simple
   GOOGLE_DRIVE_PUBLIC_URL=https://drive.google.com/...
   ```
3. Перезапустите систему

## ❓ FAQ

**Q: Как часто проверяется файл?**  
A: Каждые 15 минут (настраивается в `.env`: `SYNC_INTERVAL_MINUTES`)

**Q: Что если я переименую файл?**  
A: Нужно обновить ссылку в `.env` и перезапустить

**Q: Можно несколько файлов?**  
A: С простым режимом - нет. Используйте API режим или загружайте вручную через админ-бота

**Q: Безопасно ли?**  
A: Да, файл доступен только для чтения. Никто не может его изменить через ссылку.

**Q: Работает с любым файлом?**  
A: Да, с любым Excel файлом (.xlsx) на Google Drive

**Q: Нужен ли Google аккаунт боту?**  
A: Нет! Бот просто скачивает файл как любой пользователь по ссылке.

## 🐛 Устранение проблем

### "Не удалось скачать файл"

**Проверьте:**
1. Ссылка правильная?
2. Доступ "Любой, у кого есть ссылка"?
3. Файл не удален?
4. Интернет работает?

**Решение:**
```bash
# Проверьте вручную - откройте ссылку в браузере
# Должен скачаться файл

# Проверьте логи
docker-compose logs scheduler
```

### "Файл скачался, но не парсится"

**Проверьте:**
1. Это точно Excel файл (.xlsx)?
2. Файл не поврежден?
3. OpenAI API работает?

**Решение:**
```bash
# Скачайте файл вручную и протестируйте
python parsers/test_parser.py
```

### "Синхронизация не происходит"

**Проверьте:**
```bash
# Планировщик запущен?
docker-compose ps scheduler

# Логи планировщика
docker-compose logs -f scheduler

# Статус в админ-боте
/status
```
